## 🚀 Overview — Beyond the Standard Frame

There is a moment, deep in the archives of interactive entertainment, when a story so vast demands a canvas equally vast. The Fallen Order Ultrawide Companion was born from that very need — a quiet rebellion against the tyranny of the 16:9 rectangle. It is not simply a mod. It is a lens through which distant horizons stretch further, starships begin to feel gargantuan, and the towering silhouettes of forgotten worlds finally occupy the space they were always meant to claim.

This repository is the spiritual successor and creative reimagining of the original **FallenOrderUltrawide** project by RoseTheFlower, expanding it into a comprehensive panorama restoration toolkit. Where the original focused on the essentials, this companion suite dives deeper — multi-monitor orchestration, dynamic field-of-view calibration, camera distortion correction, and a philosophy that no widescreen enthusiast should ever have to squint at black letterbox bars again.

It is the difference between watching a film through a keyhole and standing at the edge of the galaxy itself.

Built for **2026** and beyond, this toolkit is tuned for modern hardware while remaining approachable for those who simply want their screens to breathe. It respects the original vision, adds meaningful layers, and provides a robust, documented foundation for contributors and tinkerers the world over.

## 🌠 What Makes This Project Different

Most display modification tools treat widescreen as an afterthought — a checkbox buried in a settings menu. We treat it as the primary creative constraint. The Fallen Order Ultrawide Companion approaches every aspect of the experience from the panoramic point of view first.

- **Panorama-First Design** — Every utility is built around ultra-wide intent, not retrofitted to it.
- **Modular Architecture** — Enable only the modules you need, from FOV scaling to HUD repositioning.
- **Config-Driveable** — Plain-text, human-readable configuration for every module.
- **Reversible Operations** — Nothing is permanent; every change can be rolled back gracefully.
- **Multi-GPU Aware** — Detects and respects multi-adapter setups.
- **Community-Maintained** — A living document influenced by continuous feedback.

## 🧭 Feature Constellation

### 🖥️ Ultra-Wide & Super Ultra-Wide Rendering
- Native support for 21:9, 21:10, 24:10, 32:9, and 48:9 aspect ratios.
- Automatic aspect detection with a manual override for exotic setups.
- Padding-aware rendering pipeline that avoids stretched HUD elements.

### 🔭 Dynamic FOV Calibration
- Per-scene FOV profiles for cinematic moments versus gameplay.
- Smooth interpolation to prevent jarring transitions between camera states.
- User-defined FOV curves via configuration segments.

### 🌐 Multimonitor Orchestration
- Independent rendering surfaces for triple-monitor surround configurations.
- Bezel compensation routines for physical monitor gaps.
- Aspect-aware centering that keeps focus on the primary display.

### 🎨 Distortion & Camera Correction
- Horizontal FOV compensation for spherical projection quirks.
- Vignette neutralization routines for edge lighting consistency.
- Optional chromatic-aberration harmonization for cinematic tone.

### 🧩 HUD & UI Repositioning
- Anchored UI layout presets for widescreen corners.
- Minimap scaling with edge-safe margins.
- Dialogue and subtitle safe-zone adjustments for readability.

### 🗂️ Configuration Management
- Layered profiles: global, per-display, per-session.
- Instant reload without restarting the experience.
- Diff-based change previews before applying.

### 🧪 Diagnostics & Logging

### 🌍 Multilingual Interface

### 📱 Responsive Utility Panel
- Adaptive control surface that reshapes itself across resolutions.

### 🛎️ Always-On Assistance

- Guided troubleshooting paths for common scenarios.

### ♿ Accessibility Considerations

## 🛠️ How the Toolkit Fits Together

The Fallen Order Ultrawide Companion is conceptually divided into four cooperating layers:

1. **The Sensor Layer** — Detect displays, read resolution capabilities, and observe runtime state.
2. **The Interpretation Layer** — Translate hardware facts into actionable aspect and FOV decisions.
3. **The Application Layer** — Apply rendering, camera, and UI adjustments in a controlled, reversible manner.
4. **The Observation Layer** — Log, visualize, and report the outcomes, offering transparency at every step.

Each layer communicates through a documented contract, meaning contributors can safely extend one without destabilizing another. This is software design as a star chart — each point carefully plotted so no traveler gets lost.

## 🧪 Testing Philosophy

No change reaches the mainline without passing through a gauntlet of checks:

- **Aspect Matrix Tests** — Behavior verified across a grid of common and uncommon ratios.
- **Regression Screens** — Visual snapshots compared against prior baselines.
- **Configuration Fuzzing** — Malformed config files must fail gracefully.
- **Cold-Start Scenarios** — First-run behavior tested on clean environments.
- **Compatibility Sweep** — Broad verification across display adapters and drivers.

Testing is treated not as a hurdle but as a promise — a covenant with every user that their next session will be as stable as the last.
